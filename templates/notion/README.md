# Notion templates

These are **paste-ready page bodies** (not outlines). Copy the markdown into a Notion page, or recreate a database from the property table. Headings, tables, and checklists are Notion-friendly.

1. **[Research Database](research-db.md)** — create a Notion database with the listed properties, then duplicate the page body as the entry template. Includes two Spec-to-ship example rows.
2. **[PRD](prd.md)** — full Spec-to-ship PRD (problem, MVP ships, acceptance, demo beats, SoT, escalation, DoD). Worked example is marked **EXAMPLE** so you can clear and reuse.
3. **[Decision log](decision-log.md)** — one decision per row. Three hackathon example rows (Spec-to-ship winner; repo name `Hackathon-Builder-Grok_Bot`; public+MIT).

Keep full research here; post ≤5-line summaries + links in the Grok Bot group.
