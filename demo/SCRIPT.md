# Demo Script (2–5 min)

**0:00** Mark: one objective — “Ship grok-bot-spec-to-ship kit.”  
**0:20** Orchestrator plans once; `@` each Bot with owner/deliverable/SoT/DoD.  
**0:45** Researcher + Product Design in parallel → Notion/PRD evidence (room: ≤5 lines + link).  
**1:30** `@Engineer` handoff → public repo/PR.  
**2:15** `@Reviewer` one pass vs SoT; gaps or pass.  
**2:45** Orchestrator escalates one judgment to Mark (e.g. public + license).  
**3:30** Mark decides → team closes; viewer sees PR trail + `examples/live-run/` — not six chat tabs.
