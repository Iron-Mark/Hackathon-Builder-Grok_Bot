## Video (storyboard clip)

`video/showcase-2min.mp4` is a ~2-minute stand-in cut from the PNGs + dark text slides, encoded H.264 `yuv420p` +faststart. It follows the Showcase beats so Pages is not an empty player:

1. **0:00–0:20** — One objective
2. **0:20–0:50** — `@` handoffs (hero infographic)
3. **0:50–1:20** — README + `bots/`
4. **1:20–1:45** — `examples/live-run/`
5. **1:45–end** — PR trail — not six chat tabs
